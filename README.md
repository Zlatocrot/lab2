# Домашнее задание к работе 2

## Условие задачи

Стоимость погонного метра красного шелка стоит $X$ золотых. Сколько заплатил Грей за ткань для своей бригантины если общая площадь парусов на ней $S$ м$^2$, а ширина ткани в рулоне $L$ см.

## 1. Алгоритм и блок-схема

* **Алгоритм**
  1i. Начало
  2. Задать исходные данные: $S = 104$, $X = 8$, $L = 13 / 100$ (перевод см в м);
  3. Вычислить итоговую стоимость по формуле: $\text{stoimost} = (S / L) \cdot X$;
  4. Вывести результаты расчетов с подстановкой всех значений в текст.
  5. Конец

## 2. Реализация программы

```c
void dz_15()
{
    float S, X, L;
    float stoimost;

    S = 104.;
    X = 8.;
    L = 13. / 100.;

    stoimost = (S / L) * X;
    printf("Грей заплатил %f золотых за парус площадью %f и длиной рулона %f при стоимости %f за метр\n", stoimost, S, L, X);
}
```

## 3. Результаты работы программы

Грей заплатил 6400.000000 золотых за парус площадью 104.000000 и длиной рулона 0.130000 при стоимости 8.000000 за метр
